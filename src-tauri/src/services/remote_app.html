Choose a transcription provider and model, or use server defaults. For DeepSeek voice, use model ID deepseek-voice-transcription; its service detects the language. Record sends WAV audio for transcription; replies can be spoken on this device.

Create agent

              
An empty allowed-tools list uses the default repository tools, including writing. To restrict access, list exact tool names: repo.list_tree, repo.read_file, repo.search, repo.write_file, repo.replace_range or repo.apply_patch. Supported legacy aliases also work; unrecognized names grant no tools. Agent model bindings are managed under Models; team and skill links are managed under Teams and Skills.

Workflow stage routing
