Create agent

              
An empty allowed-tools list uses the default repository tools, including writing. To restrict access, list exact tool names: repo.list_tree, repo.read_file, repo.search, repo.write_file, repo.replace_range or repo.apply_patch. Supported legacy aliases also work; unrecognized names grant no tools. Agent model bindings are managed under Models; team and skill links are managed under Teams and Skills. Prompt template references are stored but are not currently applied to agent prompts.

External planner defaults

            
These defaults apply to new external planner conversations. Each conversation keeps its original product scope. Server environment variables can override the provider and model. Browser session settings remain separate.

              

            

          

          

            
Workflow automation

Workflow stage routing

            
Roles are checked in order, first among the assigned team and then among other active agents. Leave both lists empty to use the stage defaults.

              
Coordinator review runs only when an active coordinator is available. Push preparation and Git push are system stages, so their role lists do not select an agent.
