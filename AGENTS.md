## Organization environment contract

For project creation, worktree setup, full-stack tests, database lifecycle,
staging, or production deployment, read `~/work/.org/environments.md` and use the
`product-environments` skill. If `ORG_DEV_ROOT` selects another shared checkout,
read its `environments.md` instead. Install shared agent discovery using that
checkout's `bin/install.py` on each development machine. Product repositories own
their runtime adapters. Follow project-specific instructions and user directions.
